# USERDIE Digital Tests

Директория содержит тестовые сценарии и проверки качества платформы.

---

## Назначение

Здесь будут размещаться:

- автоматические тесты;
- проверки компонентов;
- тестовые сценарии;
- контроль качества релизов.

---

## Принцип

Каждый значимый функциональный модуль должен иметь проверку.

---

## Quality Gate

Перед выпуском Release:

- тестирование;
- проверка безопасности;
- проверка документации;
- технический аудит.
