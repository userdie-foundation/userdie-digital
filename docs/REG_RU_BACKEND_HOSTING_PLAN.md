# Historical hosting proposal — superseded

**Status:** superseded on 2026-11-16. This document is retained only as a record of the earlier REG.RU-first proposal. It is not an approved hosting decision and must not be used to provision infrastructure.

The current decision is to design USERDIE Digital as an international, provider-independent platform while keeping new recurring spend at **€0**. No new VPS, managed database, paid cloud resource, DNS change, mail change, or production deployment is authorized.

See the current source of truth:

- [International zero-cost backend readiness](INTERNATIONAL_ZERO_COST_BACKEND_READINESS.md)

The public website remains on its existing GitHub Pages deployment. Backend development and testing continue with the existing Node.js 22, Docker, PostgreSQL, GitHub Actions, and Resend integration, subject to current plan limits. Real personal data and public account features remain disabled until the production release gates are satisfied.
