# Реестр активов USERDIE Digital — проектная схема

**Статус:** проектная спецификация, не подключённая база данных и не утверждённый регламент учёта.

## Назначение
Описать минимальную структуру записи для финансовых инструментов, имущества, прав и интеллектуальных ресурсов. JSON Schema находится в `schemas/asset-record.schema.json`.

## Принципы
1. Право на актив, наличие объекта и стоимость подтверждаются раздельно.
2. Любая оценка содержит дату, валюту, метод, источник, допущения и статус независимой проверки.
3. Отсутствующие сведения явно обозначаются как отсутствующие; значения не выводятся из предположений.
4. Документы хранятся в защищённом хранилище; в записи указываются ссылки/идентификаторы, а не копии чувствительных документов.
5. Не использовать персональные данные в демонстрационных записях. Идентификаторы владельцев в реальном контуре должны быть минимизированы и контролироваться правами доступа.
6. Изменения значимых полей должны отражаться в отдельном append-only журнале аудита с актором, временем, полем, причиной и ссылкой на основание.
7. Схема не определяет сама по себе юридическую допустимость, право собственности или корректность оценки.

## Обязательные контрольные точки до production
- Утверждены классификатор и регламент подтверждения прав.
- Назначены владелец данных, оценщик и проверяющий; конфликт интересов фиксируется.
- Реализованы аутентификация, RBAC и авторизация на уровне каждой записи.
- Файлы доступны через защищённые ссылки с проверкой типа, размера, антивирусной обработкой и журналированием.
- Настроены резервные копии, отдельные права доступа и периодические тесты восстановления.
- Есть политика хранения/удаления, реагирование на инциденты и журнал аудита.
- Проведены тесты качества данных, миграции и восстановления.

## Демонстрационные значения
В интерфейсе используются только записи с префиксом `DEMO-`. Они не отражают фактические активы, правообладание или стоимость фонда.
