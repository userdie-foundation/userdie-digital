# Website integration

The public site is maintained in the `website/` directory of this repository. Changes should be reviewed in a pull request before merging to `main`.

The first version is an informational prototype only. It does not process forms, store personal data, or accept donations. Verify official legal details, contact information, privacy requirements, and donation details before launch.
