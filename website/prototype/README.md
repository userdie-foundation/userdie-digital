# Прототип USERDIE DIGITAL

Утверждённый визуальный стиль главной страницы перенесён в `website/index.html` и `website/styles.css`. В этой папке сохранены связанные экраны платформы и кабинета заявителя, оформленные в том же стиле.

## Почему это не копия стороннего шаблона

Рассмотренные GitHub-шаблоны для благотворительных сайтов не предоставляли подтверждённую лицензию в метаданных репозитория, а файл LICENSE не удалось подтвердить. Поэтому чужой код не переносился. Этот прототип использует типовые UX-паттерны некоммерческих сайтов, но разметка, стили и тексты написаны для проекта отдельно.

## Что включено

- русскоязычная адаптивная главная страница;
- отдельный экран `platform.html` с картой шести будущих модулей: кабинет заявителя, программы, партнёры, прозрачность, роли и безопасность;
- экран `applicant-cabinet.html` — статический макет кабинета заявителя с демонстрационным путём обращения;
- переходы между главной, картой платформы и макетом кабинета;
- навигация по разделам фонда;
- блоки о фонде, направлениях, участии и прозрачности;
- переходы между главной страницей, картой платформы и макетом кабинета заявителя;
- доступная ссылка пропуска навигации, заметный фокус клавиатуры и учёт `prefers-reduced-motion`;
- никаких настоящих платёжных интеграций, отправки персональных данных или неподтверждённых показателей.

## Проверка перед принятием

1. Проверить отображение на мобильном, планшете и широком экране.
2. Проверить все переходы после размещения Pages.
3. Согласовать подтверждённые сведения о программах, контактах и реквизитах.
4. Провести доступность и браузерную проверку.
5. Не считать демонстрационные экраны production-функционалом и не подключать сбор пожертвований без утверждённого платёжного процесса.

## Просмотр

Открыть `index.html` в этой папке локально, затем перейти по ссылке «Карта платформы». Экран `platform.html` описывает будущие модули, а `applicant-cabinet.html` показывает только визуальную концепцию заявительского кабинета. Оба экрана статические: без авторизации, отправки форм, API или базы данных. Локальный просмотр возможен без GitHub Pages. Главная страница публикуется из папки `website` через GitHub Actions; перед объявлением релиза нужно отдельно подтвердить успешный деплой и проверить публичный домен.
