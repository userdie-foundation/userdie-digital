# USERDIE Digital Core

Core содержит фундаментальные системные компоненты платформы.

## Responsibilities

Core отвечает за:

- базовые типы данных;
- системные интерфейсы;
- общие правила платформы;
- фундаментальную бизнес-логику.

## Principles

Core не должен зависеть от конкретного пользовательского интерфейса.

Core должен быть:

- modular;
- testable;
- secure;
- documented.
