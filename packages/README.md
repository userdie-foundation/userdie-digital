# USERDIE Digital Packages

Директория содержит общие программные модули платформы.

---

## Назначение

Здесь будут размещаться:

- общие библиотеки;
- повторно используемые компоненты;
- системные модули;
- интеграционные пакеты.

---

## Архитектурный принцип

Каждый пакет должен:

- иметь отдельное назначение;
- быть документирован;
- проходить проверку качества;
- не создавать лишних зависимостей.
